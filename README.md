# EndlessWar Notifier (EW Notify)

Уведомления о событиях в игре [EndlessWar](https://endlesswar.live) в реальном времени.

Локальное Windows-приложение на базе **Tauri 2 + Rust + Svelte 5**, которое неинвазивно анализирует входящий игровой трафик через **WinDivert** (режим sniff) и отправляет мгновенные уведомления в системный трей Windows и Telegram.

---

## Возможности

- 🛡️ **Безопасность (Zero-Risk):** работает в режиме сетевого сниффера — без внедрения в память игры, DLL injection или перехвата функций (нулевой риск детекта античитом).
- 🔍 **Автоопределение endpoint'ов:** автоматически находит процесс `EndlessWar.exe` и его активные TCP-соединения через системную таблицу Windows. Поддерживается и ручной режим (порт `7777`).
- 👥 **Многооконность и защита от дублей:** раздельный кулдаун на каждое окно игры (`remote:port -> local:port`) и подавление дубликатов (burst dedup) при одновременной работе LAN + VPN.
- 🔐 **Шифрование токена (DPAPI):** токен Telegram-бота автоматически шифруется на диске средствами Windows DPAPI (привязан к текущей учетной записи Windows).
- 🤖 **Telegram-бот:** поддержка нескольких получателей, команды `/start`, `/myid`, список `/users` (только для админа) и переключение рассылки прямо из GUI.
- 🔔 **Системный трей:** сворачивание при закрытии окна, быстрый старт/стоп мониторинга из меню трея.
- 🛠️ **Инструменты отладки:** встроенная консоль логов, live-дамп пакетов с экспортом в паттерн, а также автономные CLI-утилиты `sniff` и `match_hex`.

---

## Требования

- Windows 10 / 11 (64-bit)
- Права Администратора (манифест `requireAdministrator` встроен в приложение для загрузки драйвера WinDivert)
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (предустановлен в Windows 10/11)

## Быстрый старт

1. Скачайте свежий установщик `ew_notify_*_x64-setup.exe` или архив `ew_notify_portable.zip` со страницы **Releases**.
2. Запустите приложение от имени администратора.
3. В разделе **Настройки**:
   - Укажите токен бота от [@BotFather](https://t.me/BotFather) и нажмите **«Запустить бота»**.
   - Напишите боту `/start` в Telegram, затем `/myid`, и скопируйте свой ID в поле **Admin chat ID**.
4. В разделе **Дашборд** нажмите **«Начать мониторинг»**.

> **Паттерны из коробки:**
> - `DEATH` (`00FE06032C010000`) — гибель персонажа
> - `STOP_FARM` (`4E00FE110061...`) — остановка автофарма

## Сборка из исходников

Для сборки требуются [Rust](https://rustup.rs/) и [Node.js 20+](https://nodejs.org/).

```bash
# Установка зависимостей интерфейса
npm install

# Запуск в режиме разработки
npm run tauri dev

# Сборка релизного инсталлятора и бинарников
npm run tauri build
```

Готовые файлы сборки находятся в:
- Инсталлятор: `src-tauri/target/release/bundle/nsis/`
- Бинарный файл: `src-tauri/target/release/ew_notify.exe`

## Автономные CLI утилиты

В проект включены отдельные консольные утилиты для отладки:

```bash
# Пакетный сниффер в консоли (только совпадения паттернов)
cargo run -p ew_notify --bin sniff -- --matches-only

# Офлайн-проверка hex-байтов без WinDivert и без админ-прав
cargo run -p ew_notify --bin match_hex -- 00FE06032C010000
```
