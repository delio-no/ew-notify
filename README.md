# EndlessWar Notifier (ew-notify)

Уведомления о событиях в игре [EndlessWar](https://endlesswar.live) в реальном времени.

Приложение пассивно анализирует входящий игровой трафик через сетевой драйвер **WinDivert** (без внедрения в процесс игры) и отправляет мгновенные уведомления в Telegram и системный трей Windows.

---

## Возможности

- 🛡️ **Безопасность:** работает в пассивном режиме сетевого сниффера — нулевой риск детекта со стороны игры.
- 🔍 **Автоопределение:** автоматически находит процесс `EndlessWar.exe` и активные игровые соединения.
- 👥 **Поддержка окон:** раздельные кулдауны и защита от дубликатов на каждое запущенное окно.
- 🤖 **Telegram-уведомления:** личные сообщения или рассылка в чат/группу с управлением списком получателей прямо из интерфейса.
- 🔔 **Системный трей:** сворачивание в фон и быстрый старт/стоп мониторинга из меню трея.
- 🔐 **Безопасность данных:** токен Telegram-бота шифруется средствами Windows DPAPI.

> **Предустановленные паттерны:**
> - `DEATH` — гибель персонажа
> - `STOP_FARM` — остановка автофарма

## Быстрый старт

1. Скачайте архив **`ew-notify-portable.zip`** со страницы **[Releases](https://github.com/delio-no/ew-notify/releases)**.
2. Распакуйте архив в любую удобную папку.
3. Запустите `ew-notify.exe` (требуются права администратора для работы фильтра трафика).
4. В разделе **Настройки**:
   - Укажите токен бота от [@BotFather](https://t.me/BotFather) и нажмите **«Запустить бота»**.
   - Напишите боту команду `/start` в Telegram, затем `/myid`, и скопируйте свой ID в поле **Admin chat ID**.
5. В разделе **Дашборд** нажмите **«Начать мониторинг»**.

## Сборка из исходников

Для сборки требуются [Rust](https://rustup.rs/) и [Node.js 20+](https://nodejs.org/).

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run tauri dev

# Сборка релизной версии
npm run tauri build
```

Собранный исполняемый файл находится в `target/release/ew-notify.exe`.
